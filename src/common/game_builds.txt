# Game builds whose addresses were checked by hand. On one of these Canopy
# uses the addresses below as they are and searches nothing. On any other
# build it searches with the patterns in game_addresses.txt, and the features
# that write saves stay off.
#
#     build <TimeDateStamp> size=<SizeOfImage> <label>
#     <Name> <RVA>
#     <Name> none
#
# none means the build has no such site, as when an update drops the code a
# patch rewrote; only optional addresses may be none.
#
# A build matches when both numbers of the running village.exe's PE header
# match. Every name is an address game_retail.h declares with GAME_ADDRESS,
# or a field it declares with GAME_FIELD, whose line holds the build's value
# instead of an RVA. Canopy is compiled for one layout, so a feature whose
# field has another value here stays off on that build.
#
# scripts\add_game_build.bat adds a build: it searches the new exe, lists what
# to check by hand, and writes the section once you agree.
# `canopy addresses <village.exe> --build-section "<label>"` prints a section
# without the review.
